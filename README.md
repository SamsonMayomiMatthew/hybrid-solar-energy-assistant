# AI-Driven Hybrid Solar Mini-Grid Load & Energy Management Assistant

## Overview
This capstone project simulates and optimizes energy management for hybrid solar photovoltaic (PV) and grid power systems. Built using Python and Streamlit, it ingests time-series telemetry data to monitor solar generation, load demand, and battery state-of-charge (SoC), providing automated AI recommendations to prevent power bottlenecks and manage loads efficiently.

## Features
- **Real-Time Simulation Dashboard:** Visualizes 24-hour trends in solar output and facility load.
- **AI Recommendation Engine:** Evaluates battery thresholds and solar yield to recommend load-shedding or high-load utilization windows.
- **Interactive UI:** Built with Streamlit for quick deployment and accessibility.

## Tech Stack
- Python
- Streamlit
- Pandas & NumPy
